# 🌐 AS Exports – Packaging Solutions Website

## 🏢 About Project

This is the official website of **AS Exports**, a manufacturer and exporter of high-quality packaging products including PP woven bags, FIBC jumbo bags, non-woven products, paper boxes, and tarpaulin solutions.

The website is designed to showcase products, generate business inquiries, and support global export clients.

---

## 🚀 Features

* ✅ Fully responsive design (mobile + desktop)
* ✅ SEO-optimized product pages
* ✅ Product-wise separate pages
* ✅ WhatsApp inquiry integration
* ✅ Export-focused content
* ✅ Fast loading and optimized images
* ✅ Clean UI with category-based navigation
